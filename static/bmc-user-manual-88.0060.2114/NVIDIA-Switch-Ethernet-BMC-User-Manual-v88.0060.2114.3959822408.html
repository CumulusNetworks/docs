NVIDIA Switch Ethernet BMC User Manual v88.0060.2114

The NVIDIA Baseboard Management Controller (BMC) operating system provides management and configuration capabilities for NVIDIA switch platforms.

This operating system provides a suite of management options, incorporates API, which enables administrators to easily configure and manage the system chassis management.

These pages provide information about the scope, organization, and command-line interface of NVIDIA BMC operating system as well as configuration examples.

This user manual applies to systems that use the Ethernet‑based switch BMC for Spectrum-6 platforms.
